# Mneme 3.12.2 — Context recall fix and a package install path

## English

A maintenance release with no migrations. The index format is unchanged and nothing needs to be rebuilt.

- **Context recall inside a project (#11):** `context "Orbit database" --project orbit` returned nothing even when `notes/orbit-database.md` existed. The project words were removed from the query but still required in the note name. The name match now drops them on both sides when the query names the project. A query that names another project, or no project, still abstains.
- **Install with uv or pipx (#10):** `uvx --from git+https://github.com/haliksuveyt/mneme mneme-install --vault <path>` installs the same files as the release ZIP. See [INSTALL-PIP.md](../INSTALL-PIP.md). The package is not on PyPI.
- **Documentation (#10):** a "Why Mneme" section and a terminal demo in the README, `CONTRIBUTING.md`, `SECURITY.md`, `CHANGELOG.md`, issue templates, an English multi-machine guide, and setup and archive folders under `docs/`.
- **Tests (#10):** temp-directory cleanup retries transient Windows errors, so the suite no longer fails at random on Windows.

Still by design: a question that uses a word found in neither the note body nor its name ("datastore" for a note about SQLite) returns nothing.

Update from your vault with `python3 mneme.py update` (Windows: `py -3 mneme.py update`). Notes and preferences are preserved by the managed update flow.

## Türkçe

Geçiş içermeyen bakım sürümü. İndeks biçimi aynı, yeniden kurmak gerekmez.

- **Proje içinde bağlam araması (#11):** `notes/orbit-database.md` varken `context "Orbit database" --project orbit` sonuç döndürmüyordu. Proje kelimeleri sorgudan çıkarılıyor ama not adında hâlâ aranıyordu. Sorgu projeyi adıyla anıyorsa ad eşleşmesi artık bu kelimeleri iki taraftan da düşürür. Başka bir projeyi anan ya da hiç proje anmayan sorgu yine sonuç döndürmez.
- **uv veya pipx ile kurulum (#10):** `uvx --from git+https://github.com/haliksuveyt/mneme mneme-install --vault <klasör>` sürüm ZIP'iyle aynı dosyaları kurar. Ayrıntı [INSTALL-PIP.md](../INSTALL-PIP.md) içinde. Paket PyPI'de değil.
- **Belgeler (#10):** README'de "Neden Mneme" bölümü ve terminal demosu, `CONTRIBUTING.md`, `SECURITY.md`, `CHANGELOG.md`, issue şablonları, İngilizce çok makine rehberi, `docs/` altında kurulum ve arşiv klasörleri.
- **Testler (#10):** geçici klasör temizliği Windows'taki geçici hataları yeniden dener; test paketi Windows'ta artık rastgele düşmez.

Bilerek aynı kalan: ne not gövdesinde ne adında geçen bir kelimeyle sorulan soru (SQLite notu için "datastore") sonuç döndürmez.

Vault içinde `py -3 mneme.py update` ile güncelle; macOS/Linux'ta `python3 mneme.py update` kullan. Yönetilen güncelleme akışı notları ve tercihleri korur.

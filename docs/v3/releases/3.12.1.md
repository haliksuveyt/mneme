# Mneme 3.12.1 — Secret filter and MCP fixes

## English

A maintenance release with no new features or migrations. Thanks to Matt Abate for reporting all three issues.

- **Secret filter, prefixed names (#5):** with `secret_filter` on, names such as `DB_PASSWORD=`, `OPENAI_API_KEY=`, `client_secret=`, `refresh_token=`, `AWS_SECRET_ACCESS_KEY=` and `SECRET_KEY=` are now redacted, in text, query strings and fact keys. Earlier versions wrote these values to the vault unless the value itself had a known provider shape.
- **Secret filter, custom literals (#6):** `secret-patterns.txt` literals are replaced in one longest-first pass, so a shorter literal can no longer leave the tail of a longer secret behind or damage a `[REDACTED]` marker.
- **MCP server (#7):** non-object `params`, a lone surrogate, deeply nested JSON and unexpected handler failures now get a JSON-RPC error. They used to end the server.

If you use `secret_filter`, check notes written while it was on for values under prefixed names: this release only affects new writes and does not change existing notes.

Update from your vault with `python3 mneme.py update` (Windows: `py -3 mneme.py update`). Notes and preferences are preserved by the managed update flow.

## Türkçe

Yeni özellik veya geçiş içermeyen bakım sürümü. Üç sorunu da bildiren Matt Abate'e teşekkürler.

- **Sır filtresi, ön ekli adlar (#5):** `secret_filter` açıkken `DB_PASSWORD=`, `OPENAI_API_KEY=`, `client_secret=`, `refresh_token=`, `AWS_SECRET_ACCESS_KEY=` ve `SECRET_KEY=` gibi adlar artık metinde, sorgu dizgelerinde ve fact anahtarlarında sansürlenir. Önceki sürümler bu değerleri, değerin kendisi bilinen bir sağlayıcı biçiminde değilse vault'a yazıyordu.
- **Sır filtresi, özel literal'ler (#6):** `secret-patterns.txt` literal'leri tek geçişte, uzundan kısaya değiştirilir; kısa literal artık uzun sırrın kuyruğunu bırakamaz, `[REDACTED]` işaretini de bozamaz.
- **MCP sunucusu (#7):** Nesne olmayan `params`, tek surrogate, aşırı iç içe JSON ve beklenmedik işleyici hataları artık JSON-RPC hatası alır. Bunlar önceden sunucuyu kapatıyordu.

`secret_filter` kullanıyorsan, filtre açıkken yazılmış notlarda ön ekli adların altındaki değerleri kontrol et: bu sürüm yalnız yeni yazımları etkiler, mevcut notları değiştirmez.

Vault içinde `py -3 mneme.py update` ile güncelle; macOS/Linux'ta `python3 mneme.py update` kullan. Yönetilen güncelleme akışı notları ve tercihleri korur.
